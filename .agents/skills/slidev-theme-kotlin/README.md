# slidev-theme-kotlin Skill

A locally authored Agent Skill for [`slidev-theme-kotlin`](https://github.com/nomisRev/slidev-theme-kotlin),
the Slidev theme this deck uses (`theme: kotlin` in `slides.md`).

It complements the upstream `slidev` skill: that one covers base Slidev, this one
covers everything the Kotlin theme adds on top.

## Contents

| File | Topic |
|------|-------|
| `SKILL.md` | entry point: quick start, cheat sheet, authoring rules |
| `references/layouts.md` | `default`, `cover`, `intro`, the cover text column |
| `references/kodee.md` | Kodee mascot variants, size, position, scale |
| `references/code-windows.md` | IntelliJ code windows, identity icons, `console` panel, sizing |
| `references/folded-imports.md` | folded imports and the `// Example` marker |
| `references/magic-move-between.md` | morphing code across slide boundaries |
| `references/drawn-annotation.md` | `DrawnAnnotation` props, placement, timing, styling |
| `references/code-decorations.md` | `InlineCompilerError`, `SmartCast`, `Warning`, `TypeHint`, `InlineValue` |
| `references/annotation-editor.md` | the development-only visual geometry editor |
| `references/snippets-cli.md` | `slidev-kotlin-snippets` compilable sources |
| `references/static-content.md` | handout, `llms.txt`, sitemap, analytics, hash links |
| `references/theme-config.md` | full `themeConfig`, fonts, IntelliJ formatter guard |

## Source

Written from the theme's own documentation at version **0.13.0**
(`node_modules/slidev-theme-kotlin/README.md` and `components/README.md`). When the
theme is upgraded, re-check those two files for changes.

This skill is maintained in-repo and is **not** managed by `skills-lock.json`.
